# Security

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability** (GitHub private vulnerability reporting / Security Advisories). Do not open a
public issue for a security problem.

Useful to include: what is affected (the `tadam` command, the engine, a file format), how to reproduce it,
and what an attacker could do with it.

## Scope

- This repository: the `tadam` command, the engine, the skill and the sample world.
- Problems in the TadamShow website or its API can be reported the same way; they will be passed on.

## Keys

Never paste an OpenAI key or a TadamShow studio key into an issue, a pull request or a report. If a key
has leaked, revoke it first (OpenAI dashboard; your TadamShow studio page), then report.
