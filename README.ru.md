# Студия ТадамШоу

Инструменты, чтобы делать мультфильмы кукольного театра для [ТадамШоу](https://tadamshow.com): кукольный
движок, команда `tadam` и скил для Claude Code. У вас на диске лежит **папка мира**; Claude пишет
сценарий, делает кукол и декорации, сам смотрит кадры и показывает вам сцену в локальном плеере. Когда всё
готово, одна команда отправляет работу в ТадамШоу на одобрение.

> Состояние: начало. Работают `tadam doctor`, `new`, `hero make` / `hero check`, `set make`, `check`, локальный
> плеер и кадры (`play`, `frames`, `film`, `cover`), движок, связь с ТадамШоу (`join`, `login`, `push`, `pull`, `diff`,
> `status`), заявки (`submit`, `studio-version`, `reply`, `withdraw`, `unpublish`), `review` владельца и скил.

English: [README.md](README.md).

## Установка за 5 минут

Нужно:

1. **Python 3.11+** — https://www.python.org/downloads/
2. **Godot 4.7** (обычная сборка, не .NET) — https://godotengine.org/download/
   В `PATH` (как `godot`, `godot4` или `godot_console`) или полный путь в переменной `TADAM_GODOT`.
3. **ffmpeg** вместе с `ffprobe` — https://ffmpeg.org/download.html
4. **Свой ключ OpenAI** в переменной окружения `OPENAI_API_KEY` — https://platform.openai.com/api-keys
   На нём рисуются ваши куклы и декорации; ничего платного от нас нет. Не кладите ключ в файлы репозитория;
   лучше всего — менеджер секретов (он передаст ключ одной команде: `skey run --only OPENAI_API_KEY --
   tadam hero make …`).
5. **Ключ студии** (`tds_…`) — для отправки работ и чтобы слышать закадр в локальном плеере. Запустите
   **`tadam join`** сами в терминале: почта, код из письма, правила студии целиком, и вы сами набираете
   «согласен»; ключ приходит один раз и хранится в вашей папке настроек (на экран не выводится). На другом
   компьютере: `tadam login` (та же почта и код), или `tadam login --key` с ключом из кабинета, или
   `TADAM_STUDIO_KEY`. Без ключа закадр идёт субтитрами. Никогда не вставляйте ключ в чат.

Потом:

```bash
git clone https://github.com/unbywyd/tadamshow-studio.git
cd tadamshow-studio
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS / Linux: source .venv/bin/activate
pip install -e .
tadam doctor
```

`tadam doctor` проверяет Python, Godot, ffmpeg, ключ OpenAI (только что он задан; значение не печатается) и
временную папку, и говорит, чего не хватает и где это взять. Код выхода 1 — не хватает обязательного.

## Сколько это стоит

Деньги стоит только рисование (ваш ключ OpenAI), всё остальное бесплатно. Набор рисует **по умолчанию в
качестве medium** (`--quality low | medium | high` у `hero make` и `set make`; `--help` показывает умолчания).
OpenAI считает картинки по токенам, а не поштучно; сколько реально стоило в medium (ноябрь 2026):

| что | картинок | примерно |
|---|---|---|
| герой (`hero make`) | портрет + выкройка (+1 за каждую перерисовку, не больше 2) | $0,011 + $0,038 ≈ **$0,05** |
| декорация (`set make`) | 1 комната + по 1 на предмет | **$0,04–0,1** |
| в `high` | | в разы дороже (одна картинка high стоила около $0,25) |

Каждая платная команда печатает, сколько картинок нарисовала и сколько это стоило по токенам из ответа API
(цены за токен с датой — в `src/tadam/prices.py`; они могут меняться), и сохраняет расход в `meta.json` (куклы
или `sets/<slug>/meta.json`).

## Начать за 5 минут

Claude расспросит об идее, напишет «библию», сделает героев и декорацию (перед платной генерацией назовёт цену),
напишет сценарий, сам посмотрит кадры и покажет серию в плеере. Когда понравится, отправит рубрику; вы
записываете роли на сайте и говорите, когда подавать заявку.

1. Установите всё (выше) и запускайте `tadam doctor`, пока он не скажет, что всё на месте.
2. `tadam join` в своём терминале (можно позже: без ключа работает всё, кроме отправки).
3. Откройте Claude Code в этом репозитории (или в любой папке, назвав полный путь к `skill/SKILL.md`) и скажите
   Claude: **«прочитай skill/SKILL.md и помоги мне сделать рубрику»**

## Команды

```bash
tadam new world my-world --title "Моя рубрика"   # папка мира (world.json с «библией»)
cd my-world
tadam new hero cow --name "Корова"                # heroes/cow/hero.json
tadam hero make cow "a calm brown cow in a raincoat"   # кукла: рисует ВАШИМ ключом, режет, проверяет
tadam new set barn                                # sets/barn/kit.json: опишите комнату и мебель
tadam set make barn                               # декорация: рисует ВАШИМ ключом, пишет set.json
tadam new episode 1 --cast cow=cow                # episodes/1/script.json (сценарий версии 2)
tadam check 1                                     # что не так, простыми словами, и длина серии;
                                                  # выход 1 при ошибках; --json; --verbose — и заметки info
tadam frames 1 --sheet                            # один PNG: середина каждого плана с подписью (смотрит Claude)
tadam frames 1 --shot sh3 --at 1.5                # один кадр одного плана; --json печатает пути в JSON
tadam frames 1 --shot sh3 --around 1.5            # шесть кадров вокруг момента одной полосой: движение
tadam play 1 [--shot sh3 --at 1.5 --paused]       # окно играет серию со звуком; пробел — пауза, стрелки — шаги,
                                                  # M — отметка, B — библиотека действий, Esc закрывает;
                                                  # правки мира показывает сразу
tadam play where                                  # где окно остановилось: план, секунда, кадр, что играет каждый
                                                  # герой, какие строки сценария в работе (скил: watching.md)
tadam strip <рисунок.png> --template 4            # рисунок из КАДРОВ по кругу (пламя, ткань, крыло):
tadam strip <рисунок.png> <полоса.png> --count 4  # полоса-заготовка, потом нарезка; бесплатно (скил: frames.md)
tadam film 1                                      # MP4-черновик (картинка, закадр, музыка, субтитры)
tadam hero check cow                              # все действия движка на герое (hero make запускает сам;
                                                  # ~30 с, герой в юбке 1–2 мин)
tadam cover [1] [--shot sh2 --at 1.5]             # обложка рубрики из кадра (бесплатно), без субтитров

tadam join                                        # стать редактором: почта, код, правила, «согласен» — набираете ВЫ
tadam login [--key]                               # этот компьютер: почта + код (или готовый ключ, ввод скрыт)
tadam rules [--terms]                             # прочитать правила студии
tadam push                                        # проверка, затем отправка только изменённого; печатает ревизию
tadam pull [slug]                                 # ревизия сервера: слияние в эту папку или новая папка
tadam diff [rev [rev]]                            # что изменилось: по файлам, в сценарии — по планам и шагам
tadam status [--json]                             # рубрики, серии, заявки, замечания, чего не хватает
tadam studio-version 1 <videoId>                  # ролик, собранный на сайте, — студийная версия серии
tadam submit 1 "записка"                          # заявка владельцу (отказ со списком, пока чего-то не хватает)
tadam reply "текст" [--shot sh3]  |  tadam withdraw  |  tadam unpublish "причина" [--episode 1]
tadam review list | show <id> | approve <id> | return <id> "..." [--shot sh3 "..."] | reject <id> "..."
                                                  # только владелец проекта (служебный ключ: tadam login --staff)
```

У каждой картинки и каждого звука мира есть происхождение в `sources.json` в корне папки (`own`, `generated`
с инструментом, `licensed` с лицензией и ссылкой; ключ-папка с `/` на конце покрывает свои файлы): `tadam check`
даёт ошибку на файл без него и на мат в любом тексте (спорные слова — предупреждение), по тем же правилам, что
и сервер.

`hero make --mannequin` и `set make --placeholder` рисуют кодом бесплатные заглушки (деревянный манекен,
простая комната), чтобы расставить сцену до платной генерации. `tadam check --engine` дополнительно
проигрывает каждый план в движке без окна. Служебная папка `.tadam/` мира (сцены движка, титры, закадр, кадры,
ролики, проверочные картинки и журналы `hero make` / `set make`) не коммитится и не отправляется. Обложка —
`cover.png`, `.jpg` или `.webp` в корне (или файл из поля `cover` в world.json).

Пример `examples/sock-bureau` лежит в репозитории набора, чтобы его читать и играть; свои рубрики делайте в
папке вне репозитория. Тесты прогоняют `tadam check` на каждом примере (0 ошибок, 0 предупреждений).

Все JSON-файлы набор пишет с переводами строк LF, а куклу узнаёт по содержимому её rig.json, так что checkout,
поменявший переводы строк, ничего не ломает; `tadam push` отправляет JSON с LF на любой системе. Картинки
хранятся компактными PNG (без потерь: невидимые пиксели вычищены, сжатие по максимуму).

Локально ничего не записывается: у героев нарисованные головы, рот двигается, пока герой говорит реплику, а
реплика идёт субтитром с именем героя. Реплика без записи длится, сколько её читает спокойный чтец
(`tadam.timing`: 0,4 с + слова / 2,3 в секунду + 0,25 с, и ещё 0,4 с плана после). `--board-preview` рисует то,
что покажет сайт с записанным лицом (заглушку на месте лица и голову того размера, что делает сайт), — чтобы
кадр совпал. Закадр озвучивает сервер ТадамШоу (`POST /api/studio/tts`: уходят только текст и ключ голоса),
он хранится в `.tadam/tts/`; `--no-voice` оставляет субтитры. На Linux без экрана кадры и ролик идут через
`xvfb-run`.
