# examples

- [sock-bureau](sock-bureau/) — «Бюро пропавших носков» / "The Lost Sock Bureau": a small complete world (two
  painted heroes, one painted set, one episode of 10 shots, about 40 s, Russian with English). Own pictures
  generated with the kit, no third-party rights; how to play it is in its README.

The examples live here to be read and played; make your own worlds in a folder outside the kit's repository. The
kit's tests run `tadam check` on every world in this folder: 0 errors and 0 warnings.
